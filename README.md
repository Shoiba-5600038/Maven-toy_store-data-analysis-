# Maven Fuzzy Factory – E-commerce Data Analysis

## Project Overview

This project focuses on analysing e-commerce website performance using the Maven Fuzzy Factory dataset. The objective is to understand website traffic, customer browsing behaviour, order conversion, marketing channel performance, product sales and revenue.

SQL was used to explore the data and perform business analysis, while Power BI was used to create an interactive dashboard and visualise key performance metrics.

## Business Objectives

- Analyse website sessions and order volume over time.
- Measure session-to-order conversion rate.
- Evaluate marketing channel performance.
- Analyse revenue per order and revenue per session.
- Identify product performance trends.
- Analyse refunds and their financial impact.

## Dataset

The project uses the Maven Fuzzy Factory dataset, which contains multiple related tables:

- `website_sessions` – website session and traffic source information.
- `website_pageviews` – website page browsing activity.
- `orders` – order-level information.
- `order_items` – product-level sales and cost information.
- `products` – product details.
- `order_item_refunds` – refund information.

## Tools Used

- SQL – Data exploration, joins, aggregations and business analysis.
- Power BI – Data modelling, DAX measures and dashboard visualisation.
- Excel – Data validation and exploratory analysis (if used).

## Business Questions

1. What is the trend in website sessions and order volume?
2. What is the session-to-order conversion rate, and how has it trended?
3. Which marketing channels have been most successful?
4. How has revenue per order evolved?
5. What is the trend in revenue per session?
6. Which products contribute the most to revenue?
7. What is the refund trend and its impact on sales?
